Chrome extension

Accessibility extension

AccessiView is a Chrome extension I made for the Design for All course at CUT. It lets you change how a website looks and reads, with features like dark mode, bigger text, a dyslexia overlay and colourblind filters. The changes are applied directly to the page you're viewing. I made it to make browsing easier for people with different visual and reading difficulties, giving them more control over how websites look and how they use them.

Visit the site →

Interactive map

Voices of Cyprus

This is an Interactive history map which is called Voices of Cyprus is an interactive map about the history of Cyprus, covering events from 10,000 BC to 1500 AD. Instead of going through a normal timeline, you can move around the map and explore where different people and events actually happened. I built it with Leaflet.js. The map is live, so you can click around and explore it yourself.
